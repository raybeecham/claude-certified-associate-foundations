# Module 4 Quiz and Remediation Prompts

Use these prompts to practice workflow-integration judgment without reproducing proprietary course questions.

## 1. Ambiguity detector

```text
Review these requirements. Identify any term that could lead two competent implementers to build materially different solutions.
For each ambiguous item, explain what is missing and draft a measurable clarification question.
```

## 2. Requirement testability audit

```text
For each requirement, state whether it has a measurable actor, trigger, input, output, threshold, deadline, and acceptance test.
Return Ready, Needs clarification, or Conflicting.
```

## 3. Synthesis-versus-calculation map

```text
Decompose this planning task into:
- research;
- synthesis;
- exact calculation;
- assumptions;
- human judgment; and
- approval.
Route each material calculation to code execution or deterministic logic.
```

## 4. Quantitative trust chain

```text
Design a reproducible analysis workflow for this planning problem.
Include data checks, business rules, formulas, intermediate outputs, reconciliation, assumption review, and final decision ownership.
```

## 5. Prototype escalation test

```text
Assess whether this artifact or helper has become operational infrastructure.
Consider number of users, frequency, official decisions, data sensitivity, failure consequence, support expectations, integrations, and recovery requirements.
Conclude: remain a prototype, harden locally, or escalate to engineering/architecture.
```

## 6. Dependency inventory

```text
For this AI-assisted helper, list every person, team, process, report, or decision that now depends on it.
Identify what would happen if it were unavailable or wrong for one day, one week, or one reporting cycle.
```

## 7. Delegation boundary quiz

```text
Classify every step as AI-appropriate, code-executed, collaborative, human-retained, deterministic, tool-owned, or storage-owned.
Justify each classification using reversibility, stakes, accountability, and side effects.
```

## 8. Irreversible-action scan

```text
Find any step that signs, sends, files, pays, publishes, grants access, changes an official record, or commits the organization.
Make each one a separate workflow stage and define the required approval.
```

## 9. Stakeholder statement repair

```text
Rewrite these overbroad AI capability statements.
For each, state the bounded AI tasks, excluded authority, observed value and scope, limitations, human review gate, and external-action control.
```

## 10. Three-audience communication

```text
Describe the same workflow for:
1. a technical or professional lead;
2. an executive sponsor; and
3. a client risk function.
Adapt depth and emphasis while preserving the same capability boundary, metrics, uncertainty, limitations, and approval model.
```

## 11. Distractor analysis

```text
For each incorrect answer, explain why it fails to address the controlling property.
Look for distractors based on stronger models, polished wording, repeated prompting, hidden approval, or vague automation claims.
```

## 12. Five-domain scenario generator

```text
Create five original scenario questions covering:
- ambiguous requirements;
- verified quantitative planning;
- prototype-to-infrastructure escalation;
- human-retained authority; and
- stakeholder communication.
Provide four choices, the best answer, and a concise rationale.
```

## 13. Full workflow review

```text
Evaluate this proposed AI-assisted workflow end to end.
Check requirements, sources, calculations, prototype maturity, delegation, approvals, state, failure handling, value evidence, limitations, and stakeholder expectations.
Conclude with release, revise, escalate, or reject.
```

## 14. Oral certification drill

Answer in under 45 seconds:

```text
A small Claude-built helper is now used by several teams for an official process. What changes, and why?
```

A strong answer should mention dependency, reliability, security, support, ownership, architecture, monitoring, recovery, and escalation beyond casual prompt iteration.

## 15. Retention card

```text
Ambiguous requirement      → quantify and clarify
Exact planning figure      → execute and reconcile
Shared operational helper  → engineering escalation
Approval or signing        → human-retained
Credible stakeholder claim → bounded task + evidence + limits + human gate
```
