# Module 6 Prompt Notebook: Module Introduction

Use fictional, synthetic, public, or explicitly authorized scenarios. Do not place confidential policies, restricted data, private incident details, credentials, or nonpublic risk assessments in this notebook.

## 1. Governance framing

```text
Evaluate this proposed Claude use:
[scenario]

Explain why governance is a practitioner decision rather than a policy-only exercise.
Identify:
- the immediate decision;
- affected people;
- policy boundaries;
- data and feature concerns;
- accountable owner;
- required verification; and
- possible approve, constrain, redesign, defer, or reject outcomes.
```

## 2. Diligence review

```text
Apply the Diligence competency to this use case:
[scenario]

Ask:
- Who owns the decision?
- What evidence is required?
- Which policy or standard applies?
- What data classification must be confirmed?
- Which feature or Skill needs vetting?
- What approval evidence should be retained?
- What monitoring and escalation are required?

Do not assume permission when evidence is missing.
```

## 3. Delegation assessment

```text
Apply Delegation criteria to this task:
[task]

Assess:
- reversibility;
- stakes;
- accountability;
- required expertise;
- affected parties;
- transparency;
- external actions;
- failure consequences; and
- what must remain human-controlled.

Conclude with:
- appropriate AI contribution;
- retained human authority;
- required controls; and
- whether the use should proceed.
```

## 6. Sensitive-data first pass

```text

[workflow and data description]
```
