# Module 6 Key Takeaways Prompts

These prompts reinforce the five durable lessons from Governance, Risk & Responsible Use.

Use fictional, synthetic, public, or explicitly authorized scenarios. Do not paste confidential policy, restricted records, credentials, private audit findings, or real personnel data into public study materials.

---

## 1. Five-takeaway recall

```text
Explain the five durable takeaways from Module 6:

1. Governance is a practitioner skill.
2. Screen use cases with Delegation criteria.
3. A Skill is software.
4. Classify data before it enters a feature.
5. Ethical risk hides in ordinary outputs.

For each takeaway, provide:
- a one-sentence explanation;
- the most common failure mode;
- one practical example; and
- one exam distractor to reject.
```

## 16. Escalation threshold test

```text
- disputed fairness standards;

- surveillance, manipulation, or power imbalance;

- decide with specialist consultation; or
- escalate to the authorized governance, ethics, legal, privacy, security, or professional function.

Provide the reasoning packet to send with the escalation.
```
