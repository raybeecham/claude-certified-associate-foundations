# Practice Exams

The repository includes three original practice exams:

- **Practice Exams 1 and 2:** balanced 28-question simulations with four questions from each study domain.
- **Practice Exam 3:** a full 60-question simulation weighted to the public Claude Certified Associate — Foundations blueprint and containing both multiple-choice and multiple-response items.

All questions are newly written study material. They are not live, recalled, reconstructed, leaked, or proprietary certification items.

## Recommended conditions

- Closed notes
- No web search
- One uninterrupted sitting
- Record start and finish time
- Mark uncertain items without immediately changing them
- Review every distractor afterward

### Suggested timing

| Exam | Questions | Suggested time |
|---|---:|---:|
| Practice Exam 1 | 28 | 56 minutes |
| Practice Exam 2 | 28 | 56 minutes |
| Practice Exam 3 | 60 | 120 minutes |

These practice scores are not official predictors of certification results.

## Review method

Classify each miss:

- **Knowledge:** The concept was not known.
- **Reading:** A material clue was overlooked.
- **Judgment:** Two plausible controls were not prioritized correctly.
- **Layering:** The selected answer solved a different problem than the controlling issue.
- **Execution:** The answer changed without evidence, time was mismanaged, or the selected option did not match the intended choice.

For each miss:

1. Name the controlling domain.
2. Identify the clue that should have controlled the answer.
3. Explain why the selected distractor was attractive.
4. Write one scenario variation that would make that distractor correct.
5. Record the decision rule to apply next time.

## Suggested interpretation

This is an internal study scale, not the official scaled-score calculation.

### Practice Exams 1 and 2

| Score | Suggested action |
|---:|---|
| 90–100% | Review only weak objectives and volatile facts |
| 80–89% | Target missed domains, then retest |
| 70–79% | Repeat module labs and quizzes before retest |
| Below 70% | Rebuild domain notes and delay full-exam repetition |

### Practice Exam 3

| Raw score | Suggested action |
|---:|---|
| 54–60 | Review uncertain items and volatile product facts |
| 48–53 | Target the weakest two domains, then retest with new scenarios |
| 42–47 | Revisit the relevant decision frameworks before another full attempt |
| Below 42 | Return to module lessons, quizzes, and applied exercises |

Regardless of percentage, remediate every critical miss involving privacy, unauthorized access, unsupported high-impact advice, prompt injection, unfair exclusion, unverified calculations, missing human review, or unsafe side effects.
